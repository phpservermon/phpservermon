Release Notes v5.1.0
====================

Highlights
----------
* Faster status and server detail pages by streamlining uptime lookups and caching performance stats.
* Web cron responses flush earlier to keep the UI responsive during checks.
* Weekday diagnostic reports now run automatically at 9:00 with refreshed incident summaries.
* Added a monitoring checklist to help teams plan coverage.

Performance
-----------
* Cached status page performance statistics to reduce repeated calculations.
* Reduced latency when loading server view and edit screens.

Monitoring & Diagnostics
------------------------
* Added a weekday 9am diagnostic report schedule.
* Updated incident email summaries for clearer messaging.
* Improved uptime lookup flow for status pages.

Documentation
-------------
* Added a monitoring checklist to guide coverage planning.
